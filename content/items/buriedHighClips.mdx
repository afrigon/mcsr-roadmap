From O58 down, every extra level adds more mining and building before the clip. The rule is regular,
so one pattern covers every depth.

## How it works

| Clip | From O58 |
| ---- | -------- |
| Shift clip | Mine 5 and build 1 under you, plus one more per O level. |
| Normal clip | Build 2. |

- Each O level costs about 1.1 s, so deep spawns leave little spare time for tall setups.
- A gold pickaxe reduces the time lost.

## How to practice

1. On the practice map, set O58, O59 and O60, and clip out of each.
