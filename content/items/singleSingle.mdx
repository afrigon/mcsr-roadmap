When both bridge ramparts are single chests, there is less loot and fewer piglins, but a fast route
still exists: Single Single, built around the Mogul hole. Calisthenicuber gets 14 piglins, all in
within a minute.

## How it works

- Single ramparts are short, with no boxy roof; the chest sits under a few blocks and can be buried
  deep in netherrack.
- Start exactly like cracksmoker or soog. The initial aggro is optional: skipping it is safer but
  pulls fewer piglins.
- Don't craft the chalice gold block you carry; you need it to aggro later.
- At the end of your build, drop down, place a block and mine one block below the hole: that is the
  Mogul hole. Mine the gold block to aggro, and immediately throw gold into the hole.
- When the piglins stop arriving, open the blocks that let the lower piglins up. One of them can be
  gilded blackstone, which a piglin will try to trade with, so keep gold ready.
- There is no auto funnel. Once all are trading, loot the chests; skip the second single if it isn't
  worth the trip.

## How to practice

1. In LlamaPag's bastion practice map, set both ramparts to single.
2. Practice the shared start with soog, so you can switch once you see the rampart.
