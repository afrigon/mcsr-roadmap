Every setup depends on the tower, so you need to name it before your pearl lands. The ten obsidian
towers around the fountain each have a fixed height.

## How it works

| Name | Top y | Note |
| ---- | ----- | ---- |
| Small Boy | 76 | Never the 1/8 tower in a real game. |
| Small Cage | 79 | Iron bars to about 83. |
| Tall Cage | 82 | Iron bars to about 86. |
| M-85 | 85 | |
| M-88 | 88 | |
| M-91 | 91 | |
| T-94 | 94 | |
| T-97 | 97 | |
| T-100 | 100 | |
| Tall Boy | 103 | |

- The cages are the two towers with iron bars around their crystals.
- The numbers in the names are the towers' heights, so a name tells you the minimum non-offset
  standing height: tower height + 5.

## How to practice

1. On the practice map, randomise the tower and name it from the spawn platform before pearling.
