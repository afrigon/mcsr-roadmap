A thin-resolution macro squeezes the game window into a narrow vertical strip. Only what is inside that narrow view is rendered, so entity counts and pie-chart slices react to exactly where you look, which turns a rough direction into a precise one.

## How it works

- The macro tool resizes the window on a hotkey; press it again to return. Toolscreen calls this mode Thin; Waywall can set up the same resize.
- It is the standard window for:
  - **Mapless buried treasure**: watching the pie chart spike change as you look across a chunk border.
  - **E-ray**: reading the F3 entity counter while you turn, to find the bastion.
  - **Preemptive** stronghold scans with the pie chart.
- Toolscreen adds magnifier overlays, which help on high-resolution monitors where the F3 text and pie chart get small.
- Set the macro's required game state to "in world", so typing the hotkey letter in chat or menus doesn't resize the window.

## How to practice

1. Bind thin mode to an easy key and check that the pie chart and F3 text stay readable.
2. On a buried treasure practice seed, toggle thin on and off while scanning, and learn how the spike looks at your resolution.
