StandardSettings is a mod in the Ranked pack that resets your options to a saved set every time a world is created. Once you rely on it, every run starts with the same settings, binds and debug toggles, and you never waste time fixing them mid-run.

## How it works

- Open it from Options, then the book-and-quill button, then StandardSettings. The values there are what each new world starts with.
- Change settings here, not in the normal options menu: a change made in the normal menu is reverted at the next world.
- The toggle at the top turns all resetting on or off. Each option also has its own toggle on the right, so you can leave one option (full screen, for example) alone.
- Press Ctrl+F to search for an option by name.
- Turn on **F3 pause on world load** near the bottom of the list.
- It also resets debug states (chunk borders, hitboxes, perspective) and the pie chart directory, and has "on world join" values for FOV, render distance, entity distance and GUI scale.
- The settings are stored in `.minecraft/config/mcsr/standardsettings.json`, which you can also edit in a text editor.

## How to practice

1. Copy every value from your core settings and keybinds into StandardSettings.
2. Create a new world and check that nothing changed back.
3. Each time you want to change something later, do it in StandardSettings and test with a new world.
