Navigation is pattern recognition, and the fastest way to build it is volume. StrongholdTrainer lets
you run strongholds back to back with timing and feedback.

## How it works

- StrongholdTrainer is a Fabric mod for Minecraft 1.16.1. It times stronghold runs, records
  statistics and gives feedback on your navigation.
- It includes models trained to navigate strongholds optimally, which you can compare your choices
  against. These need an x86 64-bit system; `/stinfo model` explains them.

## How to practice

1. Install the mod in a separate practice instance.
2. Run strongholds in blocks and watch your average time, not single runs.
3. When the model chooses differently from you, work out which rule (doors, stairs, five-ways, room
   count) explains its choice.
4. Add the preemptive read once plain navigation is consistent.
