Take the low front towers one height up, to y95, from the same standing block 28 −27. This adds M-88,
which only works from y95, and gives the dragon more time to come down on the others.

## How it works

| Tower | Standing | Height |
| ----- | -------- | ------ |
| Small Boy (76) | 28 −27 | 95 |
| Small Cage (79) | 28 −27 | 95 |
| Tall Cage (82) | 28 −27 | 95 |
| M-85 | 28 −27 | 95 |
| M-88 | 28 −27 | 95 |

- Same build, same bed position: only the standing height changes, so the bed timing changes.
- The bed explodes when the dragon is lower relative to you than at y90, so learn the y95 rhythm
  separately.

## How to practice

1. On the practice map, cycle the five front towers at y95.
2. Alternate y90 and y95 on the same tower until you can switch rhythm at will.
