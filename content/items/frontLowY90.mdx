Zero the low front towers (Small Boy, Small Cage, Tall Cage, M-85) at y90 with one standing block,
28 −27. The same block covers y95 next, including M-88. One coordinate covering five towers makes
this the first set worth memorizing.

## How it works

| Tower | Standing | Heights |
| ----- | -------- | ------- |
| Small Boy (76) | 28 −27 | 86, 90, 95 |
| Small Cage (79) | 28 −27 | 86, 90, 95, 99 |
| Tall Cage (82) | 28 −27 | 90, 95, 99 |
| M-85 | 28 −27 | 90, 95, 99 |
| M-88 | 28 −27 | 95, 99 |

- A non-offset setup needs a standing height of at least tower height + 5, otherwise the bed breaks
  the crystal. That is why M-88 starts at y95.
- Older guides use 28 −26 and y87 or y88. 28 −27 and y86 are the current values, confirmed in
  doogile's and kohout's pinned corrections.
- Front is more forgiving than back because the front node is further from its tower.

## How to practice

1. On the practice map, cycle through the four towers at y90, then all five at y95.
2. Read the node and rotation during the first pearl.
