The triple stack is the optimal way to build a zero setup, faster than the standard staircase build.
A fast build misplaces blocks more often, so learn a backup for each misplaced block.

## How it works

- thecamo6's T-97 y99 example clips show the build on a tall tower.
- When a block lands in the wrong spot, finish with the backup placement instead of rebuilding.

## How to practice

1. On the practice map, build the triple stack on T-97 y99 until it no longer misplaces.
2. Misplace a block on purpose and finish with the backup.
