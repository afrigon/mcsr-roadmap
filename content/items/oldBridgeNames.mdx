Older guides, including the MCSR wiki's bastion routing page, named bridge bastion routes after the
rampart layout. Knowing them helps you read older guides; current routes have their own names.

## How it works

The bridge bastion has two ramparts, each a single or a triple chest layout. The old names list the
combination:

| Old name | Layout | Current routes for that layout |
| --- | --- | --- |
| Double Single | Both ramparts single | Single Single (Mogul hole) |
| Left Triple | Left rampart triple | Donkey Kong, Lodesteal, Estrogen |
| Right Triple | Right rampart triple | Soog, Bank Heist, Subway, Daisy, Cracksmoker |
| Double Triple | Both ramparts triple | Cracksmoker |

- "Buried" named routes for a bridge bastion buried in terrain; its current counterpart is not
  documented in one place.
- "Double Triple" also names a stables bastion route, unrelated to the bridge one.
