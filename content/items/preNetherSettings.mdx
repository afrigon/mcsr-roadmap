A few video settings decide whether the bastion shows up at all when you step through the portal.
Set them before entering, so the nether loads with everything the counter tricks rely on.

## How it works

| Setting | Value | Why |
| ------- | ----- | --- |
| Render distance | 16–20 | Loads chunks far enough to include the bastion. |
| Entity distance | 500% | Far entities render and count in the F3 E number, so the bastion's piglins show up. |
| Entity culling | Off | Entities behind terrain still count, so you can read the bastion through walls. |
| Planar fog (Sodium) | On | Lets the wide macro see far terrain at the screen edges. |

- If you play the overworld at a lower render distance, raise it with F3+F on the way into the
  nether.

## How to practice

1. Add the four settings to a checklist and verify them on every practice run until they're habit.
2. Use StandardSettings so entity distance, culling and fog reset correctly every world.
