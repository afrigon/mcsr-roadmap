MCSR Ranked is a mod for Minecraft 1.16.1 that matches you against another player on the same filtered seed. Installing it through Prism Launcher with the official mod pack gives you the game version, the Ranked mod and the allowed speedrunning mods in one step.

## How it works

- Install [Prism Launcher](https://prismlauncher.org) and sign in with your Microsoft account. Cracked accounts and launchers do not work, and modified clients such as Lunar are not allowed.
- Download the Ranked mod pack from the Ranked wiki's download page and import it into Prism (Add Instance, then Import). The pack contains the Ranked mod plus the speedrun-legal quality-of-life and performance mods, including StandardSettings.
- In the instance's Java settings, use Java 17 or newer (draconix recommends a version between 17 and 22; Prism's built-in Java downloader can fetch one).
- If the game runs out of memory, raise the instance's maximum memory, leaving enough for the rest of your system.
- Launch the instance and accept any Ranked update it asks for until you reach the title screen.
- Runs played with the Ranked mod installed can't be submitted to speedrun.com. If you also want to run for the leaderboard, copy the instance in Prism and remove the Ranked mod from the copy.
