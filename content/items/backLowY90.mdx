Back dragons use their own standing block, −30 25, for every low tower. Back is less forgiving than
front because the back node sits closer to its tower, so start at y90.

## How it works

| Tower | Standing | Heights |
| ----- | -------- | ------- |
| Small Boy (76) | −30 25 | 86, 90, 95 |
| Small Cage (79) | −30 25 | 86, 90, 95 |
| Tall Cage (82) | −30 25 | 90, 95, 99 |
| M-85 | −30 25 | 90, 95, 99 |

- y90 is the recommended back height for Small Boy.
- Health matters more on back: low-health back zeros are one of the main reasons to bail.

## How to practice

1. On the practice map, set the node to back and cycle the four towers at y90.
2. Mix front and back so you read the node before choosing the standing block.
