Holding F3 and pressing A or D triggers a debug command instead of strafing, so you can't move sideways while scanning the pie chart or holding F3. A split rebind in the macro tool fixes it, and tuning key repeat makes holding render-distance keys fast without double presses.

## How it works

- **Split rebind for strafing**: in Toolscreen's keyboard layout, right-click A, choose split rebind, keep what it types as A and set its trigger to a key nothing else uses (HiTrippy uses O). Do the same for D (M). Then set strafe left and right to those keys in StandardSettings, so every world binds them.
- **Alternative**: if you never use the F3+A and F3+D debug commands, add a Toolscreen hotkey for F3+A and F3+D with "block key from game" checked instead.
- **Key repeat**: Toolscreen has a key repeat start delay and key repeat delay. Lower values make a held F3+F change render distance faster, but too low and one press registers twice. HiTrippy settles on 140 ms start delay and 60 ms repeat delay; find your own middle ground.
- Waywall offers key rebinding on Linux through its config.

## How to practice

1. Set up the split rebind and test it in a world: hold F3 and strafe both ways.
2. Hold F3+F and Shift+F3+F at your key repeat settings and check that single presses change render distance by exactly one.
