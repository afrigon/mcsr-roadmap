The classic gap blocks are the safe way to set up the trading hole and finish a good gap. Every
gap route and every triple to gap route ends here, so learn this layout before any faster hole.

## How it works

- Break the block you placed on the stairs to let piglins down, and mine the block in the roof:
  there are almost always one or two piglins above, and two gold blocks you'll want later.
- Dig down to make a small trading window. Piglins path into the hole by themselves through it.
- Cap off the stairs again, then dig down for up to six gold blocks. Not all six always spawn, so
  check every spot.
- Craft the ingots and throw them in the hole. If you need more, pillar up for one gold block that
  usually sits above and one hidden in the wall.
- meebie's layout places three blocks that help piglins path when you open the wall, and mines the
  diagonal blocks because piglins can't make that diagonal jump.
- Tuck into the corner to pick up trades.

## How to practice

1. In the LlamaPag map, punch a piglin, then run straight to the gap and build the layout.
2. Repeat until you place every block without looking at a guide; count late piglins each run.
