# MCSR Ranked

- The official MCSR Ranked [installation instructions](https://wiki.mcsrranked.com/install/)
- Make sure to follow the MCSR Ranked [Guidelines](https://mcsrranked.com/guidelines)

# Prism Launcher

The recommended way to configure an instance for MCSR is [Prism Launcher](https://prismlauncher.org)

# Mods

A list of speedrun-legal mods can be found here: [https://mc.sr/mods/](https://mc.sr/mods). 

For MCSR Ranked it is recommended to use one of the pre-built modpack from [https://wiki.mcsrranked.com/install/download](https://wiki.mcsrranked.com/install/download#modpack).

> [!WARNING]
> An instance with MCSR Ranked installed is not eligible for submission on speedrun.com
