Search crafting types a few letters into the recipe book's search bar so only the recipe you want
shows. It is faster and more consistent than paging or tabs, at the cost of memorising queries.

## How it works

- Press Tab, then Space to focus the search bar (it turns blue). Inside a crafting table, Tab once
  more highlights it.
- Type the query and click the recipe. Space in the centre of the grid jumps the cursor to the
  result, and Space again jumps back, so you can toggle without moving the mouse.
- A "junkless" query shows only the item you want. The optimizer below lists them per language.
- English queries from the HiTrippy and GASLEFORT guide:

| Item                 | Query          |
| -------------------- | -------------- |
| Beds                 | `be`           |
| Respawn anchor       | `aw`           |
| Bow                  | `ow` or `bow`  |
| Pickaxe, axe         | `xe`           |
| Sword                | `rd`           |
| Nether bricks and glowstone | `ne`    |
| Sticks (2×2)         | `ick`          |
| Flint and steel (2×2) | `we`          |
| Eye of ender (2×2)   | `en`           |

- Don't leave the cursor in the search bar when you need to drop an item: the drop key types into it.
  Click elsewhere first.

## How to practice

1. Learn the fortress set (beds, anchor, bow, pickaxe) first.
2. Then the bastion set (axe, sword) and the 2×2 crafts.
